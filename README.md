
# 轻小说翻译系统/智能文档翻译系统 - 功能说明

## 项目概述

本系统是一款基于 **DeepSeek API** 的智能文档翻译工具，旨在提供高效、便捷的批量文档翻译体验。特别针对轻小说等文本进行了优化，同时也支持多种语言和风格的通用文档翻译。系统集成了图形用户界面（GUI）、智能文本分块、上下文关联翻译、翻译结果缓存、API 错误重试及模型自动切换等功能，以提高翻译效率和质量，并降低 API 调用成本。

## 主要特性

*   **图形用户界面 (GUI)**: 提供直观易用的界面，方便用户添加文件、配置参数、控制任务和查看日志。
*   **多格式支持**: 支持读取 `.docx` 和 `.txt` 格式的源文件，并可将翻译结果保存为这两种格式。
*   **批量处理与文件管理**:
    *   支持通过按钮或拖拽方式批量添加文件和文件夹。
    *   允许在队列中对文件进行移除、清空和上下排序。
*   **智能翻译引擎**:
    *   集成 **DeepSeek API** 进行翻译。
    *   支持 **多语言** 目标（中文、英文、日语、韩语）。
    *   提供多种 **预设翻译风格**（标准、日式轻小说、正式）及 **自定义提示词** 功能。
    *   可选择不同的 **翻译模型**（DeepSeek-V3/DeepSeek-R1）和调整 **温度值 (Temperature)** 控制翻译的创造性。
    *   自动进行 **智能文本分块**，适应 API 长度限制，并考虑上下文连贯性。
    *   支持 **上下文关联翻译**，提高长文档翻译的流畅度和一致性。
*   **缓存管理**:
    *   自动缓存翻译结果，对相同文件（内容不变）和相同设置的翻译请求直接使用缓存，减少 API 调用。
    *   支持 **会话隔离**，不同文件或文件版本拥有独立的缓存空间。
    *   提供手动 **清除选中文件缓存** 和 **清除全部缓存** 的功能。
*   **任务控制与监控**:
    *   后台多线程处理翻译任务，避免界面冻结。
    *   支持任务的 **暂停、恢复和取消**。
    *   实时显示 **总体进度** 和 **当前文件块处理进度**。
    *   提供详细的 **实时日志** 反馈，包括处理步骤、缓存状态、API 调用、错误和警告信息。
*   **健壮性设计**:
    *   包含 API **错误重试机制**，自动处理临时的网络或服务器问题。
    *   在重试时可选择性地 **自动切换备用模型** (例如从较贵模型切换至通用模型)。
    *   提供 **API 连接测试** 功能，方便用户验证网络和密钥状态。
    *   内置简单的 **格式保留** 机制，尝试保护原文中的 Markdown 链接、代码块等。

## 重要提示

*   **API 密钥安全**: `api_key.txt` 文件包含您的个人 API 密钥。**请勿将此文件（或包含密钥内容）分享给他人**，否则可能导致密钥泄露和账户盗用。如果您需要分享本程序，请务必先 **删除或清空 `api_key.txt` 中的内容**。
*   **缓存隐私**: 缓存文件 `translation_cache.json` 会存储您的翻译原文和译文。如果您翻译了敏感内容，并且需要分享程序或清理磁盘空间，请记得 **手动删除此文件** 或使用程序内的 **【清除全部缓存】** 功能。缓存不清理会一直增大。
*   **API 费用**: DeepSeek API 是 **付费服务**。请关注您在 DeepSeek 平台上的账户余额和用量。

## 环境准备与安装

1.  **获取软件**:下载发布的可执行文件包
2.  **获取代码**:克隆代码仓库。
3.  **配置 API 密钥**:
    *   访问 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并获取您的 API 密钥。
    *   **【非常重要】** 在程序根目录下找到 `api_key.txt` 文件。
    *   将您申请到的 **完整 API 密钥** 粘贴到 `api_key.txt` 文件中并保存。确保文件中 **只有密钥本身**，没有多余的空格或换行符。API 调用是付费服务，请根据需要管理您的账户余额。

## 使用指南

### 启动程序

双击运行 `DocTranslator.exe` (或通过 `python main.py` 启动源代码)。

### 界面概览



主界面分为左右两个主要面板：

*   **左侧面板**: 文件队列管理、输出与翻译参数设置、自定义提示词配置。
*   **右侧面板**: 任务进度与状态显示、操作控制按钮、实时日志显示区域。

### 文件队列操作

*   **添加文件/文件夹**:
    *   点击 **【添加文件】** 按钮，选择一个或多个 `.docx` 或 `.txt` 文件。
    *   点击 **【添加文件夹】** 按钮，选择一个文件夹，程序将自动添加其中所有支持格式的文件。
    *   直接将文件或文件夹 **拖拽** 到左上角的 "文件队列" 区域。
*   **管理队列**:
    *   在列表中 **选中** 一个或多个文件。
    *   点击 **【移除选中】** 删除选中的文件。
    *   点击 **【清除选中缓存】** 清除选中文件的历史翻译缓存。
    *   点击 **【清空队列】** 移除列表中的所有文件（会弹出确认框）。
    *   点击右侧的 **【↑】** 或 **【↓】** 按钮调整选中文件的处理顺序。

### 翻译参数设置

在 "输出与翻译设置" 区域配置：

*   **输出目录**: 点击最右侧的文件夹图标按钮选择翻译结果保存的目录。**必须设置！**
*   **输出格式**: 选择将翻译结果保存为 "Word 文档 (.docx)" 还是 "文本文件 (.txt)"。
*   **目标语言**: 从下拉菜单选择翻译的目标语言（如：中文、英文）。
*   **翻译风格**: 选择预设的翻译风格（如：标准、日式轻小说、正式）或选择 "通用"。
*   **模型选择**: 选择用于翻译的 DeepSeek 模型（如：DeepSeek-V3）（DeepSeek-V3适应大部分翻译场景）。
*   **温度值 (0-2)**: 输入一个 0 到 2 之间的数值，控制翻译结果的创造性和随机性（常用值如 0.7、1.0、1.3）。较低值结果更确定，较高值更多样。

### 自定义提示词

*   当 "翻译风格" 选择为 **"通用"** 时，下方的 "自定义提示词" 区域会被激活。
*   您可以在文本框中直接 **输入** 您的自定义翻译指令。
*   也可以点击 **【选择文件】** 按钮加载一个 `.txt` 文件作为提示词。
*   *提示*: 一个好的自定义提示词可以显著影响翻译质量和风格。

### API 连接测试

*   在开始翻译前，可以点击 **【测试连接】** 按钮。
*   程序将尝试连接 DeepSeek API 并验证您的 API 密钥是否有效。结果会显示在日志区域和弹出的消息框中。

### 执行翻译任务

1.  确保文件已添加到队列，并且所有翻译参数已设置完毕，**特别是输出目录**。
2.  点击右侧 "操作控制" 区域的 **【开始处理】** 按钮。
3.  任务将在后台开始执行。

### 任务监控与控制

*   **进度**: "进度与状态" 区域会显示任务的整体进度和当前正在处理文件的块进度。
*   **状态**: "状态" 标签会显示当前操作（如：解析中、翻译中、保存中）。
*   **日志**: "实时日志" 区域会滚动显示详细的处理信息、缓存命中情况、API 调用结果、警告和错误。
*   **暂停/恢复**: 点击 **【暂停】** 按钮可临时中断任务；按钮会变为 **【继续】**，点击可恢复任务。
*   **取消**: 点击 **【取消】** 按钮可提前终止当前整个翻译任务。已完成的文件不受影响。

### 缓存管理

*   **自动缓存**: 程序会自动缓存成功的翻译结果。对于内容未变的文件和相同设置，再次翻译时会优先使用缓存。
*   **手动清除**:
    *   **【清除选中缓存】** (文件队列区域): 清除在文件列表中选中的特定文件的缓存。
    *   **【清除全部缓存】** (操作控制区域): **清空所有** 历史翻译缓存。请谨慎使用！
